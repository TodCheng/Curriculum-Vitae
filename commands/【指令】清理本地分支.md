# 清理本地分支（order-center）

聊天中触发：**`/【指令】清理本地分支`**（与文件名无扩展名一致；可搜索「清理」「分支」「gone」）。

**仅附加本文件、不加任何文字说明时**：视为用户要求 Agent 在**仓库根**按本文**代为执行**清理（先 `fetch --prune`，再删除 **`[gone]`** 上游的本地分支），并汇报删除了哪些分支；**若删除被拒绝**（未合并等），在对话中说明原因与可选后续操作。

## 目标

- **远程已不存在**的分支对应的 **`origin/*` 跟踪引用**：通过 **`git fetch --prune`** 清除。
- **本地仍保留、但上游已在远程删除**的分支（`git branch -vv` 中显示 **`[gone]`**）：删除对应**本地**分支，避免长期堆积。

**不做**：不删除远程仓库上的分支；不强制改写了未合并工作；默认**不**对 **`master`** / **`main`** 执行删除（即使误标为 gone，也应人工核对）。

## 你必须做的事

1. **在仓库根**执行：
   ```powershell
   Set-Location "<repo-root>"
   git fetch --prune
   ```
   必要时写明远程名（本仓库一般为 **`origin`**）：`git fetch origin --prune`。

2. **列出**待清理的本地分支（上游已 gone，且**不是**当前检出分支、**不是** `master` / `main`）：
   ```powershell
   git for-each-ref --format='%(refname:short) %(upstream:track)' refs/heads
   ```
   在输出中筛选**第二列为 `[gone]`** 的行；或用：
   ```powershell
   git branch -vv
   ```
   查看 **`[gone]`** 标记。
   - 若无任何 `[gone]`：在对话中说明「无待清理本地分支」，**跳到第 4 步或结束**。
   - 若有：向用户**简要汇报数量**（可选列出名称），再执行第 3 步。

3. **删除**（优先 **`git branch -d`**；合并关系以当前仓库状态为准）：
   - **Windows**：分支名常含中文，**不要**用 PowerShell `foreach` + `$变量` 调用 `git branch -d`（控制台编码易导致 **`branch not found`**）。请使用 **Git 自带的 `sh.exe`** 执行仓库内脚本（与 UTF-8 分支名兼容）：
     ```powershell
     Set-Location "<repo-root>"
     & "C:\Program Files\Git\bin\sh.exe" "../../.docs/scripts/【脚本】清理本地分支-上游已删除.sh"
     ```
     脚本路径：**`../../.docs/scripts/【脚本】清理本地分支-上游已删除.sh`**（命名见 **`../../.docs/specs/【规范】文档命名与分类规范.md`** §2.2.10：**`【脚本】{中文简述}.sh`**；与 `.docs/` 同仓维护，勿再用已废弃的 `.cursor/scripts/`）。若 Git 未装在默认路径，改为实际 **`...\Git\bin\sh.exe`**（或 `usr\bin\sh.exe`）。脚本逻辑：`cd` 到仓库根；排除当前分支与 **`master`** / **`main`**；对其余 **`[gone]`** 分支执行 **`git branch -d`**，失败则输出 **`FAIL: 分支名`**（多为未合并，**不要**擅自 `-D`）。
   - **macOS / Linux**：可用同等逻辑的 `sh` 脚本，或一行：
     ```bash
     current=$(git branch --show-current)
     git for-each-ref --format='%(refname:short) %(upstream:track)' refs/heads | while read -r name track; do
       [ "$track" = "[gone]" ] || continue
       [ "$name" = "$current" ] && continue
       [ "$name" = "master" ] || [ "$name" = "main" ] && continue
       git branch -d "$name" || echo "FAIL: $name"
     done
     ```

4. **收尾**（可选，便于用户核对）：
   ```powershell
   git branch -vv
   ```

## 不要做的事

- **不要**在未 `fetch --prune` 的情况下凭旧信息批量删分支。
- **不要**删除**当前**检出分支；删除前若用户在其它分支上有未提交改动，先提醒 **`git status`**，避免误操作心理预期不一致（指令不负责替用户 stash/commit）。
- **不要**默认对 **`master` / `main`** 执行 `git branch -d`。
- **不要**将 **`branch-name.txt`**、**`commit-msg.txt`** 等与 Git 清理混为一谈；本指令与提交无关。

## 与用户交互

- 若用户要求**只预览不删除**：执行到第 2 步列出 **`[gone]`** 分支后停止。
- 若远程名不是 **`origin`**：以用户指定为准（例如 **`git fetch <remote> --prune`**）。
- 若用户希望**同时清理其它远程**：按远程逐个 **`fetch <name> --prune`**，且 **`for-each-ref`** 仅针对 **`refs/heads`** 的 `[gone]` 与**该远程**的跟踪关系一致时再删（复杂场景下以 `git branch -vv` 人工确认为准）。
