# Cursor 聊天命令（`.cursor/commands/`）

- **约定**：见 **`../../.docs/specs/【规范】文档命名与分类规范.md`** §2.2.9、§3.2.11。
- **命名**：**`【指令】{中文简述}.md`** 或 **`kebab-case.md`**（二选一）。
- **用法**：在 Cursor 聊天中输入 **`/`**，选择命令（与**文件名去掉 `.md`** 一致），例如 **`/【指令】Git分支与提交`**、**`/【指令】飞书项目需求驱动开发与测试环境交付流程`**、**`/【指令】清理本地分支`**（prune 远程跟踪并删除上游已消失的本地分支）。
- **说明**：本目录文件**不是** `.docs/` 业务文档；业务规范仍以仓库根 **`../../.docs/specs/`** 为准。
